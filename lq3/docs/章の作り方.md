# 章の作り方（第2章以降）

第1章で作った仕組みを、そのまま次の章に使うための手順書。
**原則：コア（`src/core.js`）は触らない。データを足すだけで章が増えるようにしてある。**

---

## 全体像

| ファイル | 何を書くか |
|---|---|
| `src/chapters.js` | **章の決まりごと**（開始地点・ボス・物語の筋・章の終わり） |
| `src/core.js` | マップ定義・敵・呪文・店（章の分岐は書かない） |
| `src/npc.js` | NPCの配置と台詞、クエスト定義 |
| `src/world.js` | マップIDの登録（地方・種別・シーン） |
| `src/assets.js` | 絵（キャラ・モンスター） |
| `test/chapter.js` | 章データの整合性を自動で検査 |

---

## 手順

### ① マップを作る

`tools/` の生成スクリプトを雛形にする（`gen_world.py` が世界地図、章ごとの町は同様に書く）。

必ず守ること：

- **到達性を確認する**（孤立した床を作らない）
- **イベントのマスに隣接できる**（宝箱・NPC・ボスの前に立てる）
- **ワープの着地点が壁でない**

生成したら `src/core.js` の `MAPS` に追加する。

```js
zaal_town:{name:'たいしょうのまち ザール',theme:'desert',enc:false,tiles:[
  "...",
], warps:{}, warpsXY:{'x,y':{to:'world',x:..,y:..}}},
```

### ② world.js に登録する

```js
zaal_town: {region:'zaal', kind:'town', name:'たいしょうのまち ザール', scene:'SCENE_ZAAL_TOWN'},
```

- `kind` は **BGMの選択に使われる**（`town`/`in`→町BGM、`cast`→城BGM、それ以外→フィールドBGM）
- `scene` には描画設定を書く（`render:'2d'|'3d'`、テーマ、天候など）

### ③ 世界地図をつなぐ

`tools/gen_world.py` の `SPOTS` に地点を足し、山脈を1マス開けて通れるようにする。
**第1章では山と海で他地方を封鎖している**ので、章が進んだら開ける。

### ④ NPCとクエストを書く（`src/npc.js`）

```js
zaal_town: [
  {at:'8,8', spr:'villagerB', name:'しょうにん', lines:[
    {when:{flag:'ch2_xxx'}, text:['...']},   // 条件つき
    {text:['...']},                           // 既定（必ず1つ）
  ]},
],
```

- `spr` は `src/assets.js` の `CHR` にあるキー（王・王妃・近衛・メイドなど17種）
- **既定の台詞を必ず入れる**（検査で落ちる）

クエストも同じファイルに。`chapter: 2` を忘れずに。

### ⑤ 章データを書く（`src/chapters.js`）

`CH` に `2: { ... }` を足す。第1章をそのまま真似ればよい。

```js
2: {
  id:'ch2_zaal', title:'あきないの たび', region:'zaal',
  start:{map:'zaal_town', x:.., y:.., dir:'front'},
  party:['bald'], gold:.., herbs:.., waters:..,
  home:{map:'zaal_town', x:.., y:.., name:'ザールの きょうかい'},
  returnSpots:[{map:'zaal_town', x:.., y:..}],
  bosses:{ zaal_dgn2:{key:'...', clearedFlag:'ch2_...', intro:[...], after:[...]} },
  specialTiles:[{map:'zaal_cast', tile:'K', handler:'throne'}],
  onEnter:{ zaal_town:'ch2_reachedZaal' },
  talkEvents:[ {npc:'...', unless:'ch2_...', set:['ch2_...'], quest:{...}, msg:[...]} ],
  bossReward:{ '...':{set:['ch2_...'], giveKey:'...', quest:{...}, msg:[...]} },
  ending:{ trigger:'ch2_...', set:['ch2_cleared'], quest:{...},
           msg:[...], card:{title:'第2章 完', sub:'あきないの たび'}, next:3 },
},
```

### ⑥ 敵とボスを足す（`src/core.js`）

- `ENEMIES` に追加（**`src/assets.js` の `MON` に絵を必ず入れる**。忘れると検査で止まる）
- `MIDBOSS` にボスを追加
- `byMap` にマップごとの出現表、または世界地図なら `encZones` に地方を追加

### ⑦ 検査を走らせる

```
./run_all.sh
```

全部緑でなければデプロイしない。特に：

- `test/chapter.js` … 章データの書き忘れを検出（79項目）
- `test/check.js` … マップ・NPC・クエストの整合（500項目）
- `test/regress_ch1.js` … 第1章の通し。**第2章用も同様に書く**

## 第2章の通しテストの書き方

`test/regress_ch1.js` を複製して書き換える。押さえる点：

1. **物語の順序どおり**に歩いて、各段階のフラグが立つか
2. **順序を飛ばした場合**に詰まないか（第1章で実際に詰みが出た）
3. 全マスの到達性
4. ボスの勝率（`test/tune_ch1.js` を複製）

---

## つまずきやすい点（第1章で実際に起きたもの）

| 症状 | 原因 | 対策 |
|---|---|---|
| 城に入れず詰む | 順序を飛ばすとフラグが立たない | 進行済みなら通す条件を入れる |
| 玉座で門番が答える | 同じタイル記号を別の意味で使った | `specialTiles` でマップごとに分ける |
| 人がいるマスだけ床が違う | 床テクスチャを通路/それ以外で分けていた | 屋内は全面同じ床に |
| モンスターが別の絵になる | `MON` に絵を入れ忘れ | ブラウザ検査が全モンスターを確認する |
| BGMが鳴らない | 効果音と別のオーディオコンテキスト | `BGM.attach()` で共有する |

## そのまま使える仕組み（作り直し不要）

- **2Dドット絵レンダラ**：地形の自動接続・建物の屋根組み・16bitパレット
- **戦闘**：対象選択・作戦・状態異常・2D戦闘背景（地形別）
- **BGM**：場所の種別で自動切替。曲を足すときは `TRACKS` に1行
- **セーブ**：章ごとにパーティを保管。`switchChapter(2, ['bald'])` で切り替え
- **リターン**：`returnSpots` に書けば行き先に並ぶ
- **章タイトルカード**：`V.chapterCard(title, sub, done)`
- **NPCスプライト17種**：王・王妃・王女・王子・近衛隊長・近衛兵×2・メイド・執事・宮廷魔導士・村人×2・戦士・老人・老婆・神父
