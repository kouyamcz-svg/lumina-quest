# ルミナクエストIV 絵の発注プロンプト v2（1枚＝1プロンプト）

作成：2026-08-05 ／ v1 は「共通文＋個別文を自分で貼り合わせる」形で、
ファイルごと渡すと AI が勝手に図鑑カードを作ってしまった。v2 では**各ブロックを単体で完結**させた。

---

## 使い方（これだけ守る）

1. **このファイルを ChatGPT に添付しない。**添付すると全体を読んで勝手に作る。
2. 下の枠のうち **ひとつだけ** を選び、枠の中身を**まるごとコピーして貼る**。
3. 画像が1枚返ってくる。それをこの会話（Claude）にアップロードする。
4. 次の絵が欲しければ、**新しいチャットを開いて**次の枠を貼る。同じチャットで続けると前の絵に引きずられる。

会話の途中で「もっとこうして」と足すのは構わない。ただし最初の1投目は枠の中身をそのまま貼ること。

## 横向き・後ろ向きが欲しくなったら

主人公4人だけは3方向あると歩行が自然になる。ただし**正面が確定してから**。
正面画像を添付して、次を送る。

```
添付した画像と同じキャラクターの【真横向き】を描いてください。
・配色・体型・服の意匠・髪型を完全に一致させる
・進行方向は画面右向き
・同じ画風（16-bit pixel art、アンチエイリアスなし）
・背景は #FF00FF のマゼンタ単色
・枠・文字・複数コマを入れない。1枚に1体だけ、全身、直立
```

後ろ向きは【真横向き】→【真後ろ向き（顔は見えない、後頭部と背中）】に差し替える。
