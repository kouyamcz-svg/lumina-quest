# ルミナクエストIV 絵の発注プロンプト v3（実績のある型）

作成：2026-08-05 ／ v3 で確定。**イオでこの型が通り、実際にゲームに組み込み済み。**

v1 の失敗：ファイルごと渡したら AI が勝手に図鑑カードを作った。
v2 の失敗：頭身を指定しなかったので6.5頭身のリアル体型になり、24pxに縮めると顔が消えた。
v3：**頭身指定＋3面シート**。この形で成功した。

---

## 使い方（4行）

1. **このファイルを AI に添付しない。**枠をひとつだけコピーして貼る
2. 出た画像を Claude にアップロードする
3. 次の絵は**新しいチャット**で。同じチャットだと前の絵に引きずられる
4. 人間キャラは3面シート、モンスターは正面1枚（型が違うので注意）

# 【型A】人間キャラ（3面シート）

パーティ4人とNPC・グランはこの型。**下の枠をコピーし、最後の【キャラクター】だけ差し替える。**

```
16-bit pixel art sprite sheet, no anti-aliasing, limited palette.

同一キャラクターを【正面向き・真横向き（右を向く）・真後ろ向き】の
3体、左からこの順に等間隔で横一列に並べてください。
3体とも同じ配色・同じ体型・同じ服装・同じ髪型にしてください。
3体の頭の高さと足元の高さを揃えてください。

背景は #FF00FF のマゼンタ単色で完全に塗りつぶしてください。

【禁止事項】枠・カード・図鑑・パラメータ表・ステータス・説明文・名前・
ラベル・矢印・ロゴ・署名を一切入れない。地面や影を描かない。

【体型・重要】
・頭身は2.5〜3頭身のデフォルメ。頭を大きく、目を大きめに描く
・リアルな6〜8頭身にしない
・全身が縦30ピクセル程度に縮小されても、顔と装備が判別できる情報量にする

【キャラクター】
16歳の少年剣士。天空大陸の騎士団見習い。地上生まれで、父は鍛冶職人。寡黙。
・髪：黒に近い濃紺の短髪、少し跳ねている
・瞳：琥珀色
・服装：生成りのシャツに、なめし革の胴当て。質素。マントは無し
・武器：装飾のない鋼の剣を右手に持つ
```

## Claude 側でやること（発注不要）

以下は生成AIに頼まなくてよい。画像を渡せばこちらで機械的に作る。

- マゼンタの除去
- 3体の切り分け・足元と頭の高さ揃え
- 規格サイズへの縮小（人間17×30、モンスターは高さ48〜100）
- **横向きの左右反転**（エンジンは左向きが基準）
- **歩行フレーム3枚の生成**（体を1ドット沈め、足元を1ドットずらす）
- base64 化・`assets.js` 組み込み・デプロイ

## うまくいかないときの調整

- **リアルすぎる／頭身が高い** → 「頭身は2.5〜3頭身。頭を大きく」をもう一度書く
- **背景がマゼンタにならない** → 「背景全体を #FF00FF (255,0,255) の単色で塗りつぶす。グラデーション禁止」と念を押す
- **3体の背丈がバラバラ** → 「3体の頭の高さと足元の高さを揃える」をもう一度書く
- **正面しか描かない** → 型Aの3面シート指定を使っているか確認する。1体ずつ頼むと正面しか出ない
- **文字やラベルが入る** → 「文字・ラベル・矢印・署名を一切入れない」を最後にもう一度書く
