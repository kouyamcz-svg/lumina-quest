## 5-2. 「Ⅲよりクオリティが低い」への対処（M0で受けた指摘）

1. **裂け目の広場が水増しの廊下だった** → 分岐のある構造に作り直し。入口からボスまで51歩、行き止まり2本（宝箱／逃げ遅れた子ども）。**1マスの廊下に飾りの岩を置かない**（通れなくなる・脇道が抜け道になる不具合を2件出した）
2. **下層区が対称な箱だった** → 21×15に拡大。大通り・東西の路地・建物ブロック（宿／道具屋／教会／長屋）・光珠灯・広場・イオの家を配置
3. **表記がⅢのひらがなのままだった** → システム文をすべて漢字混じりに統一（攻撃／技／道具／防御／逃げる／経験値／回復…）。**イオ・セレンは「放った！」、ノエ・アマネは「唱えた！」**と職業で動詞を出し分け。`build_verify` に表記ゆれ検査を追加（Ⅲのひらがな13語が文字列に残っていないこと）

残っている課題：ボスの仮絵が中身と合っていない（木人＝ヌシガニ、ウンブラ＝Ⅲの影）。絵の用意時に解消する。

## 5-3. Ⅲからの進化：探索の仕掛け（採用した方針）

Ⅲは「歩く・戦う・話す」の3動作しかなく、ダンジョンが解く場所になっていなかった。Ⅳでは `specialTiles` 機構を土台に4種の仕掛けを実装した。

| タイル | 意味 | 挙動 |
|---|---|---|
| `O` | 動かせる岩 | 進行方向の先が床なら押せる。穴なら埋まって足場になる |
| `x` | 穴 | 通れない。岩を落とすと床になる |
| `L` / `l` | 光珠灯（消／点） | 調べると点灯・消灯。マップの灯りが全点灯で `lampGates` が発動 |
| `K` | 扉 | `locks` に鍵の指定があれば鍵で、なければ別の仕掛けで開く |

**タイル書き換えの仕組み**：`MAPS[map].tiles` の文字列を直接書き換える。描画・当たり判定・監査がすべてそのまま追従するので、読み替えの通し忘れが起きない。元の姿は `MAPS_ORIG` に保持し、`G.tileEdits` に差分を記録してセーブ/ロードで復元する。

**ソフトロック対策**：`gimmickRescue()` — 穴が1つも埋まっておらず、どの岩ももう押せない状態でマップに入ると、そのマップの仕掛けを元に戻す。詰んで進めなくなるのを防ぐ。穴のあるマップには岩を2つ以上置くことを監査で強制している。

**監査に追加した項目**：岩が最初から押せるか／穴のあるマップに岩が2つ以上あるか／まっすぐ押して届く穴があるか／光珠灯を調べられる位置か／扉に開ける手段が定義されているか。BFS到達性は `x` `O` `K` を「解けば通れる」ものとして扱う。

序章のダンジョンは両方の仕掛けを必須にした（岩で穴を埋めて中段へ → 光珠灯2つで奥の扉 → ボスの間）。

## 5-4. 行動範囲：天空大陸フィールド（`world`）

M0では町4枚しかなく、狭かった。**44×30・陸地650マスのフィールドマップ**を追加した。

- マップIDは `world`。LQ3のエンジンが `world` を特別扱いする箇所（地帯名表示・全滅時の帰還先）にそのまま乗る
- 周囲は雲海（`~`）で通行不能。**船はない**ので、陸続きでなければ到達不能になる。監査のBFS到達性を `world` にも適用している（LQ3では船前提で除外していた）
- 三段のたな（下層／中層／上層）を尾根と森で区切り、道で結ぶ。`encZones` で地帯名が変わる（下層の たな／中層の たな／上層の たな）
- 地点は6つ。**下層区（V）だけ入れる**。中層区・雲海港・光珠炉・天空城・空中庭園は `Q`（これから作る地点）で、調べると理由付きで断られる
- 下層区の東門（20,6）から出入りする。門番NPCが行き先を教える
- エンカウントは `encRate:0.09 / encGrace:4`（ダンジョンより緩め）。序章の悪夢獣が出る

M1で `Q` を順に実マップへ置き換えていく。

## 5-5. 見た目の進化：タイトル画面と戦闘演出

**タイトル画面（`ui.js` の `Title`）**
Ⅲは起動するといきなりメニューが1枚出るだけだった。Ⅳは専用のタイトル画面を挟む。雲海に浮かぶ三段の大陸シルエット、その上の城、明滅する光珠の灯り、空を横切る白竜、3層の雲海パララックス、明滅する星。**画像ファイルは使わずcanvasに全部描いている**ので、絵の支給を待たずに完成している。タップかキーでメニューへ進む。

**戦闘のダメージ表示（`view2d.js` の `pop2D` / `drawPops`）**
非ブロッキングの `V.pop({...})` を追加。戦闘中だけ数字が飛び出す。
- `dmg` 白／`crit` 金・1.5倍サイズ＋強いシェイクとフラッシュ／`pdmg` 味方の被弾は赤／`heal` 緑の `+n`／`status` 紫（「眠り！」など）／`miss` 灰
- 敵に当てた数字は敵スプライトの位置に、味方の被弾・回復は画面下のメンバー位置に出る
- 実測：ウンブラ戦40回で dmg 357 / heal 104 / crit 22 / pdmg 75 発火

Ⅲにもシェイクとフラッシュはあったが、**何がいくつ効いたかは文字を読まないと分からなかった**。数字が出ることで、buffやinflictの効果も画面で伝わる。

## 5-6. エンカウント率の基準（「遭遇が多すぎて進めない」への対処）

一度 encRate 0.24 / 猶予2歩まで上げてしまい、**6歩に1回**戦闘になって進めなくなった。レベルを稼がせようとして頻度で解決しようとしたのが誤り。**頻度は据え置き、1戦あたりの経験値で調整する**のが正しい。

| 場所 | encRate | 猶予 | 平均歩数/戦 |
|---|---|---|---|
| 裂け目の広場（ダンジョン） | 0.10 | 4歩 | 14歩 |
| 天空大陸（フィールド） | 0.07 | 5歩 | 19歩 |

序章ざこの経験値を2倍（16/22/28/36/48）、木人を40に引き上げて補償した。実測：広場を51歩歩くあいだの戦闘は平均4.0回、ボス前の到達Lvは3が中心、通し勝率90%。

## 5-7. 序章の後半（ウンブラ撃破後）

撃破直後は章末メッセージが出るだけだった。確定稿の「駆けつけたグランに認められて正式入団」を実際の手順として作った。

1. **撃破演出** — 紙片が地に着く前に消える描写。見物の夢守りの少年が顔色を変える（ノエの伏線）。広場の奥から騎士団の灯りが近づく
2. **グランが広場に現れる** — `bossReward.setTiles` で `rift_yard (12,3)` に `n` を追加。クエスト「団長への報告」が立つ
3. **逃げ遅れた子ども**（任意）— 礼に薬草2つと30ゴールド。父の鍛冶場の話が出て、イオの出自が生活のレベルで語られる
4. **町の反応が変わる** — 荷運び・技師・うわさずき・門番の台詞が撃破後／叙任後で三段階に変化。技師は「取り替えた新しい管も光が濁っている。この十年ずっとだ」と第1章の伏線を置く
5. **グランに報告** — 「怖かったか」「震えたまま立てたなら、それでいい」。HP/MP全快。「この裂け目は今夜だけのものではない」
6. **章末** — 翌朝の布告で叙任。セレンが「屋根の上で見ていた、動けなかった、次は下りる」と関係を進める。町は何もなかった顔で朝を迎え、夢守りの少年だけが灰の消えた場所を探している

**エンジンへの追加**：`setTiles` を `talkEvents` と `bossReward` の両方で使えるようにした（物語の進行でマスを書き換え、人を出したり道を開いたりできる）。`herbs` の受け取りにも対応。

**監査に追加**：npc.js の座標が実際に `n` タイルか、隣に立てるか。マップを作り直したとき座標が取り残されて「話しかけられないNPC」になる事故が実際に出たため（127項目）。

## 5-9. 序章 v3：かげのあぎとを軸にした二段構え

「かげのあぎと」を**二度出す**ことで、序章に縦の筋を通した。

**一度目（昼・光珠管の点検路）** — 新マップ。技師の依頼で東門の外へ。管に貼りついたあぎとが**光を吸っている**。イオが踏み込むと逃げられ、追えない。黒い紙片が一枚残る。**戦闘にはならない**（勝てない相手ではなく、届かない相手として置く）。

**技師への報告** — 「口だけ？　そいつは管を咥えていたか」「二十年この仕事をしてるが聞いたことがない」「……いや。一度だけある。お前の父さんが同じことを言っていた」「十年前だ。管の光が濁りはじめた年さ」。**父が同じものを見ていた**という一点で、イオの出自が物語に接続する。

**二度目（夜・裂け目の広場）** — 中ボスとして再登場。裂け目の光を吸って昼よりふくれている。「……お前か」「知ってるの」「昼に管に貼りついていた。逃げられた」。倒すとセレンが「光を食べる獣の真似、ね」「この街の光は、誰かに食べられてるのかも」と第2章の減光現象へつなぐ。

**新マップ `pipe_path`（光珠管の点検路）17×14** — 二重の回廊構造。世界地図の `X`（14,24）から入る。光珠灯2つを点けると奥の間が開き、あぎとに会える。討伐ノルマ3体もここで消化する。

**父の覚え書き（あぎとの伏線を受ける節）**
技師から「お前の父さんが同じことを言っていた」と聞いた後、家の道具棚を調べると父の帳面が出る。「三の管、また濁る」「口のような形に見えた。気のせいだと思いたい」「上に出しても通らん。下の者の話は記録に残らない」。日付は十年前で止まっている。
隣のおばさんに話すと続きが出る。「三年書いてた」「上へ持って行っては突き返されて帰ってきた」「最後の年に一度も帰ってこなかった夜がある。朝に戻って、それきり帳面を開かなくなった」。

**グランへの追及（覚え書きを読んだ場合のみ）**
叙任後、グランに父のことを聞ける。「記録は残っていない」「だがおれは覚えている」「突き返したのは当時のおれの上役だ。おれは横で黙って聞いていた」「おれは詫びる立場にない。だから代わりに約束する。お前の報告はおれが必ず上へ通す」。第5章でグランが大陸に牙を剥く動機の下地になる。

これで序章の節は**10**：家 → 技師の依頼 → 点検路とあぎと初戦 → 報告 → 父の覚え書き → 試験前半 → 模擬戦 → 上層の使者 → 裂け目（中ボス＋ウンブラ）→ 撃破後とグランへの追及。

## 5-10. 第1章「下層区の亀裂」

**筋** — 悪夢獣が下層区にだけ湧く。上層は「地上の血が呼び込んだ」と言う。合同任務で原因を追い、十年前に**塞がれた**旧管路の破れ目に巣くうオボロを討つ。章末、炉技師が「炉の光がこの十年ずっと濁ってきている」と漏らす（第2章へ）。

**新マップ2枚**
- `mid_dist`（中層区 21×15）— 技師と職人の街。宿・道具屋・神殿。上層への石段は許可証で止められる。世界地図の `V`（22,16）から入る
- `old_pipe`（旧管路 **22×25**）— 下層の地下。**入り組んだ迷路**。壁はすべて光珠管
  - 南半分（入口側）と北半分を**横一文字の亀裂**が断ち切る。岩4つのどれかを押し込んで渡る
  - 北半分の行き止まりに**光珠灯2つ・宝箱・破れた管**、南半分に**宝箱・倒れた見習い**
  - 灯り2つで最奥の隔壁が上がり、ボスの間へ
  - **設計上の注意**：調べるもの（灯り・宝箱・NPC）は通行不能なので、必ず行き止まりに置く。通路の途中に置くと道を塞いで到達不能な区画ができる（実際に出した）
  - 通し実測（実際に経路を探索して歩く）：到達Lv10〜11が中心、オボロ勝率73%
