# 第3章「重い大地」拡張案 ── 五地方降下

方針決定：地上寄港地は**5地方すべて**。各地にサブイベントを置き、「五地方の民の起源」を1章で丸ごと描く。
章題変更案：「重い大地」→**「五つの大地」**

---

## 章の構造

任務が「補給降下」から**「五station巡回降下」**になる。天空大陸は5つの供給塔を地上に持ち、光珠の恩恵（灯り・薬・保存の術）を降ろす代わりに食料と鉱石を汲み上げている――**天空と地上の関係そのもの**を、5箇所を巡ることで体感させる章。

巡回順は固定（北→東→南→西→中央）。各地は「寄港イベント（必須）＋サブイベント（任意）」の二層構造。

---

## 各地の詳細

### 1. 氷の谷（後のヴェルサ）
- **寄港イベント**：氏族の長の娘リーゼが悪夢片に攫われる。救出行で氏族の信頼を得る
- **サブイベント**：「眠らない子守唄」――谷には子供を悪夢から守る古い子守唄がある。歌詞を集めると、それが**天空から堕ちた悪夢を鎮める唄**だと判明（悪夢が地上に漏れていた傍証）
- **起源の種**：リーゼの氏族が後の**ヴェルサ王家**。IIIの「眠りから覚めない王女」の千年前に「眠りから子を守る一族」を置く対の構図
- **パーティの山**：セレン。氏族の子らに槍を教え、「重い者たち」への偏見が解ける

### 2. 湧き水の町（後のザール）
- **寄港イベント**：二つの集落が水場の権利で睨み合っている。供給塔の水路図を使って第三の水脈を掘り当て、仲裁する
- **サブイベント**：「はじまりの隊商」――仲裁後、両集落の若者が共同で荷を運び始める。護衛依頼を3件こなすと、彼らが**最初の隊商**を結成する（IIIバルドの商網の千年前）
- **起源の種**：交易路の起源。ミニ行商システム（LQ3の相場機構を小規模流用）をここだけ解禁
- **パーティの山**：イオ。「余所者同士が組むと道ができる」――自分の居場所の答えの前振り

### 3. 珊瑚の入り江（後のミナモ）
- **寄港イベント**：海の民の少女ナミが「見たことのない空の都の夢」を語り、村で気味悪がられている。ノエが彼女の力を**夢視（ゆめみ）**と見抜く
- **サブイベント**：「ふたつの家」――夢を**捧げる**家（夢守り）と夢を**視る**家（夢視）の対話。ノエがナミに「あなたの力は呪いじゃない」と伝える
- **起源の種**：ナミの血筋が後の**ミナモの巫女の家系＝セナ・ルカの祖**。IIIの姉妹の夢視の力の出どころ
- **パーティの山**：ノエ。夢守りの制度への疑問が「力の使い方は選べる」という確信に変わる

### 4. 若き霊峰（後のエルデ）
- **寄港イベント**：禁書庫から写本を持ち出して失踪した天空人の学者ゼノスが、山肌の洞で独り研究している。連れ戻すか見逃すかの選択（どちらでも進行、台詞分岐）
- **サブイベント**：「山の耳」――ゼノスは「山が竜の声を反響させる」ことを発見していた。アマネと共に山頂で白竜の声を聞く儀式。アマネが「聞く者」の役目を初めて誇りに思う場面
- **起源の種**：ゼノスの庵が後の**賢者の隠れ里**（III・ゼフの里の千年前）。「知は空から堕ちて山に棲んだ」
- **パーティの山**：アマネ。「白竜さまの口」から「アマネ」になる中間点

### 5. トロスの村（旧大陸・中央）
- **寄港イベント**：父の故郷。父が「なぜ空へ行ったのか」を知る（既定の主軸イベント。位置をここへ）
- **サブイベント**：「祠の丘」――村人と共に、村外れの丘に小さな祠を建てる手伝い。完成した祠を見てイオが呟く。「……いい場所だ。なにかを、あずけたくなる」（**結末で剣を納める祠**。ここで建てておく）
- **章ボス**：**ルプス**（Lv22-24）。祠の丘に堕ちてきた悪夢の断片が地上の狼に憑いたもの。天空の討伐記録に狼座の星名で記される。「悪夢は地上まで漏れている」ことを全員が目撃して帰還
- **パーティの山**：イオの核心。父の言葉「空の鋼は、いつか誰かを守る剣になる」

## 追加される伏線回収

| 3章で張る | 回収先 |
|---|---|
| リーゼの氏族＝ヴェルサ王家の祖 | IIIの王女（眠り姫の対の構図） |
| 最初の隊商 | III・バルドの商網 |
| ナミ＝夢視の家系の祖 | III・セナとルカの力 |
| ゼノスの庵＝賢者の里の祖 | III・ゼフとミオの里 |
| 祠の丘の建立 | 結末の剣奉納→Iの冒頭の祠 |
| 子守唄＝悪夢を鎮める唄 | 終章メーア戦の「看取り」の祝詞に旋律を引用（音楽面の伏線） |

これで**5地方すべてがI〜IIIの何かの起源**になり、「前日譚」の密度が最大化する。

## 開発量の管理（全採用でも破綻させない設計）

| 素材 | 方針 | 新規量 |
|---|---|---|
| 5地方フィールド | **LQ3のフィールドを千年前差分で流用**（町位置・道を調整、タイル置換） | 小 |
| 町マップ | 各地1つ・14×11級の小型で統一（LQ3の町の半分） | 中（5枚） |
| ミニダンジョン | 氷の谷洞とトロス街道の**2本だけ**。他3地方は町＋屋外イベントで完結 | 中（2本） |
| 敵 | 悪夢片の色違い5種＋地方獣は**LQ3の敵の時代差分（名前と色替え）** | 小 |
| NPC | 各地の起源キャラ5人＋モブ | 中 |

サブイベントは全て任意なので、**実装は「寄港イベント5本を先に縦に通す→サブを1本ずつ追加」**の順で分割納品できる。章全体の想定Lv帯は5箇所巡回に合わせて**19〜24**に広げる（ボス22-24）。経験値はEXP_MULで町周辺を薄めに調整し、5箇所回っても過剰レベルにならないようにする。
