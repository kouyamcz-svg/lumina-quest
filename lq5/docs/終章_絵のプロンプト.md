# 終章 絵のプロンプト（2026-10-13）

終章の魔物・ボス・飛空艇・印は、いま「仮の絵」で動いている（魔物はいまある絵の色を変えたもの、飛空艇と印はコードで描いたもの）。届いたら切り出して rabbit.json／wobj.json に入れ、src/template.html の終章の節の FOES の frames と tint、drawAirship・darkCastle・祠の印を差し替える。
キンコロ（坑道の奥・魔王の城の、経験値の多い魔物）はギンコロの色を金に変えて使うので、絵の発注は不要。
どれも共通の文を入れてあるので、ブロックごとにそのままコピーして使える。
