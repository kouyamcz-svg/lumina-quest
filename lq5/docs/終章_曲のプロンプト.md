## 曲A「魔王」（ガルヴァ・ゼルディオス）

スタイル欄：
```
暗く 重い ファンタジーRPGの ラスボス戦の 曲。歌なし。パイプオルガン、言葉の ない 混声合唱、低い 弦の 速い きざみ、ティンパニ、遠くで 鳴る 大きな 鐘。短調。テンポ 100前後。絶望感、千年 待った 魔王の 威圧感。16ビット時代の RPGの ラスボス曲の 雰囲気を 管弦楽で。
```

曲の 説明（歌詞欄・説明欄が ある 場合）：
```
［前奏］鐘が 3回 鳴り、オルガンの 低い 和音。
［本編］低い 弦の きざみの 上で、合唱が 不安な 旋律を 歌う。ティンパニが 打ち込む。
［中盤］金管が 魔王の 主題を 重く 鳴らす。すべての 楽器が 重なり、押しつぶされる ような 圧。
［終わり］前奏の 鐘と オルガンへ 戻り、そのまま 最初に つながる。消えて いかない。
歌なし。
```
