# 第4章 絵のプロンプト（2026-10-12）

第4章の魔物とボス（1〜9）の絵は 2026-10-12 に届き、差し替えた。残りは 10〜13（人物・外の世界の印・海の背景）。届いた絵を切り出して spr.json / rabbit.json に入れたら、src/template.html の FOES（第4章の節）の frames と tint を差し替える。

どの絵にも最初に付ける共通の文：

> 16ビット時代のRPGのようなドット絵。くっきりした黒い輪郭、細かい陰影。背景はマゼンタ（#FF00FF）一色で、地面・影・文字・枠は描かない。こまどうしは十分に間をあけ、体の大きさと立つ位置はすべてのこまで同じにする。
